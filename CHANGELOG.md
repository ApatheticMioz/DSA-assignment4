# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - Initial Archival Release

### Added
- Console-based notepad with keyboard input handling
- AVL tree-based dictionary for spell checking
- Spell check suggestions using:
  - Character substitution
  - Character omission
  - Character insertion
  - Character reversal
- Undo functionality (up to 20 states)
- File save and load operations
- Linked list for character-by-character text storage
- Queue for word tracking
- Stack for undo history management
